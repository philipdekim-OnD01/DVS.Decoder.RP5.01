# RAW 원본 재생기

저장된 DVSRAW01의 모든 레코드를 순서대로 읽고 개별 표시합니다. 입력이 늦으면 기다리며, 재생 시간을 맞추기 위해 프레임을 버리지 않습니다. 필터, 잔상, 프레임 합치기 및 영상 압축을 적용하지 않습니다. gzip은 디스크에 무손실 해제하며 원본은 읽기 전용으로 엽니다.

## 실행

Python 3.9 이상과 최신 브라우저만 필요합니다. 추가 Python 패키지를 설치할 필요가 없습니다. macOS/Linux/Raspberry Pi에서 실행할 수 있습니다.

1. 이 `player` 폴더를 내려받거나 저장소를 업데이트합니다.
2. RAW 릴리스의 `mipi-raw2-10s.dvsraw.gz`와 `mipi-raw2-10s.json`을 같은 폴더에 둡니다.
3. 터미널에서 실행합니다. 처음에는 약 2.84GB의 압축 해제 공간이 필요합니다.

```bash
python3 raw_player.py /파일경로/mipi-raw2-10s.dvsraw.gz
```

저장소 루트에서는:

```bash
python3 player/raw_player.py /파일경로/mipi-raw2-10s.dvsraw.gz
```

브라우저가 자동으로 열립니다. 열리지 않으면 터미널에 나온 `http://127.0.0.1:포트/`를 열어 주세요. 종료는 터미널에서 Ctrl+C입니다. 외부 네트워크로 데이터를 보내지 않으며 localhost에만 바인딩합니다. 다른 파일은 서버를 종료하고 새 경로로 실행합니다.

기준 JSON에 `raw_sha256`이 있으면 압축 해제/재사용 전에 바이트 무결성을 검증합니다. JSON이 없으면 기준 체크섬 미검증으로 표시하며 기존 압축 해제 파일을 임의로 덮어쓰거나 재사용하지 않습니다. 별도 JSON은 `--metadata 경로.json`으로 지정할 수 있습니다.

## 조작

- 재생/일시정지: 버튼 또는 Space
- 이전/다음 한 프레임: 버튼 또는 좌우 방향키
- 프레임 번호 입력 후 이동, 또는 슬라이더로 직접 이동
- 목표 표시 속도: 1 / 5 / 10 / 30 / 60개/초 (기기와 브라우저에 따라 더 느려집니다)
- RAW 저장: 현재 레코드의 175,680바이트 payload를 변경 없이 내보냄
- PNG 저장: 현재 표시 화면의 무손실 이미지. 내장 데이터가 포함된 RAW의 대체물이 아닙니다.
- 내장 데이터 원시 워드(BE)와 payload hex 확인

이번 기록은 호스트 수신 1,613.97개/초입니다. 60개/초로 모두 표시해도 약 26.9배 슬로모션이며, 처리 시간이 더 필요하면 더 느려집니다. 자동 재생은 마지막에서 정지합니다. 다른 탭으로 이동하면 일시정지합니다. 수동 seek는 사용자가 명시적으로 위치를 바꾸는 동작입니다.

## 보존 범위와 표시

00=검정(이벤트 없음), 01=흰색(ON), 10=파랑(OFF), 11=자홍색(미할당). 매 프레임을 새로 표시하여 이전 이벤트를 누적하지 않습니다. 따라서 손 윤곽은 필터와 잔상이 적용된 실시간 영상보다 희박하게 보일 수 있습니다.

정렬 후보를 찾을 수 없는 레코드도 건너뛰지 않습니다. 센서 이미지로 해석하는 대신 전체 RAW 바이트를 976×180 회색조 격자로 표시하고 경고합니다. RAW 저장 기능은 정렬 여부와 무관하게 원본 payload를 보존합니다.

좌표 매핑은 기존 PACK_BYTES 수신 디코더를 따릅니다. 센서 내장 번호/타임스탬프의 정확한 해석과 수신 시 손실 여부는 아직 검증되지 않았습니다. 표시되는 V4L2 순번·SOF·수신 시각은 호스트 메타데이터이며 센서 자체 누락 통계가 아닙니다. 브라우저는 각 레코드에 화면 갱신 기회를 주지만 모니터의 물리적 표시까지 측정/보증하지는 않습니다. 한 장씩 확인하려면 일시정지와 다음 프레임을 사용하세요.

## 검사

```bash
python3 raw_player.py /파일경로/mipi-raw2-10s.dvsraw.gz --check
python3 -m unittest discover -s . -p test_player.py -v
node test_decoder.js
```

검증: 실제 16,140개 레코드의 길이와 SHA-256, gzip 무손실 해제, 순번 wrap/gap, 잘린 파일/잘못된 길이 거부, 좌표 wrap, 네 가지 2비트 코드 보존, 프레임 간 누적 없음, 정렬 불일치 감지. 브라우저에서 1~71번을 순차 재생하여 표시 횟수와 고유 프레임 수가 모두 71임을 확인했습니다.
